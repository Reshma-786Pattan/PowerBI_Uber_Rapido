# Uber, Rapido & Ola – Driver Performance Analysis | Power BI

## Project Overview

This project focuses on analyzing driver performance and operational activities across three major ride-hailing platforms: Uber, Rapido, and Ola.

The objective is to transform raw driver data into meaningful business insights using Microsoft Power BI. The dashboard provides an interactive environment to explore driver performance, earnings, trip completion, cancellations, ratings, and recruitment-related metrics.

## Objectives

- Analyze driver performance across different ride-hailing platforms.
- Evaluate total trips, trip completion rates, and cancellation rates.
- Understand driver ratings and performance distribution.
- Analyze driver earnings and operational efficiency.
- Explore driver demographics and age-group distribution.
- Examine interview scores, recruitment outcomes, and verification status.
- Identify trends and patterns to support data-driven decisions.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- Microsoft Excel
- Python (Pandas and NumPy for data cleaning and preprocessing)

## Data Preparation

Before developing the dashboard, the dataset was prepared through data cleaning and preprocessing.

Key activities included:

- Handling missing values.
- Identifying and treating outliers.
- Removing duplicate records where applicable.
- Correcting data types.
- Standardizing column names.
- Improving data consistency and quality.

## Dashboard Analysis

The project is structured around four analytical areas:

1. **Driver Performance Overview** – Analyzes driver ratings, completed trips, trip completion rates, cancellation rates, and driver distribution.

2. **Earnings & Operational Analysis** – Explores driver earnings and operational performance.

3. **Recruitment & Interview Analysis** – Examines interview scores, selection outcomes, and recruitment patterns.

4. **Driver Profile & Risk Analysis** – Explores driver demographics, document verification, and background-check information.

## Key Power BI Concepts

- Power Query transformations
- DAX measures and calculated columns
- KPI cards
- Interactive slicers and filters
- Charts and data visualizations
- Data relationships and modeling
- Cross-filtering and dashboard interactions

## Project Outcome

This project demonstrates how business intelligence tools can transform raw operational data into interactive dashboards. It helps understand driver performance, operational trends, and recruitment patterns across ride-hailing platforms.
